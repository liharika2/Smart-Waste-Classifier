# ♻️ Smart Waste Classifier (Java OOP Project)

## 📌 Overview
The Smart Waste Classifier is a Java-based desktop application developed using Object-Oriented Programming (OOP) principles. The system allows users to upload an image of waste material and classifies it into categories such as Plastic, Organic, or Metal. It also provides appropriate disposal suggestions to promote eco-friendly waste management.

---

## 🎯 Objective
- To promote proper waste segregation
- To build an OOP-based real-world application
- To simulate intelligent waste classification

---

## 🚀 Features
- 📂 Upload waste image
- 🧠 Classify waste type (Plastic, Organic, Metal)
- ♻️ Suggest disposal method
- 🖼️ Display uploaded image in GUI
- 💡 Simple and user-friendly interface

---

## 🛠️ Technologies Used
- Java (Core)
- Java Swing (GUI)
- Object-Oriented Programming (OOP)

---

## 🧱 OOP Concepts Implemented
- **Abstraction** → Abstract class `Waste`
- **Inheritance** → Subclasses (PlasticWaste, OrganicWaste, MetalWaste)
- **Polymorphism** → Overriding disposal methods
- **Encapsulation** → Class-based structure

---

## ⚙️ How It Works
1. User uploads an image
2. System reads file name
3. WasteClassifier identifies type
4. Displays result and disposal method
5. Shows uploaded image
